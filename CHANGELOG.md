# Changelog

## v2.0.0

- Finalized the public dataset package, metadata, and capture-disjoint split
  files.
- Corrected the documented source and released image resolution to
  3072 × 2048 pixels.
- Added a complete data dictionary and expanded descriptions for all 11
  deposit assets.
- Added a documented Blender asset workflow and formalized the viewport-overlay
  procedure.
- Added deterministic scripts and source tables for manuscript Figures 2–6
  and Tables 1–3.
- Separated the pinned core reproduction environment from optional CNN
  benchmark dependencies.
- Added release validation and SHA-256 file-manifest support.
- Documented MobileNetV2, ResNet-18, and EfficientNet-B0 training with
  cross-entropy, CORAL, and CORN heads.
- Corrected CORAL and CORN class-probability conversion and kept
  classification-head variants separate during benchmark aggregation.
- Corrected Danh Cuong Do's name in the citation metadata.
